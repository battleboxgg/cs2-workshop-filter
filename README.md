# Workshop Spam Filter for CS2

A Chromium extension that hides the fake and spam maps flooding the **Counter-Strike 2 Steam Workshop**
(the "Mirage Online", "AWP Lego Models", "Dust2 Cheats" maps with a Russian description that only redirect you to a server).

Works in Chrome, Brave, Edge, Opera, Vivaldi and other Chromium-based browsers.

> Not affiliated with or endorsed by Valve Corporation. Steam, Counter-Strike and CS2 are trademarks of Valve Corporation.

## Features

- **Scoring instead of hard rules** – each map collects points for suspicious traits, so a single weak keyword never hides a real map.
- **Dim or hide** – suspicious maps are greyed out with a badge showing the reason; clear spam is removed.
- **Gaps are refilled** – hidden maps are replaced with the next clean maps from the following result pages, so pages stay full.
- **Block / allow authors** with one click while hovering a map card.
- **Starter blocklist** of spam authors, generated by the included crawler.
- **Fully local** – no tracking, no server, no account. See [PRIVACY.md](PRIVACY.md).

## Installation (no store account needed)

The extension is installed as an *unpacked extension*:

1. Download the latest `workshop-spam-filter-x.y.z.zip` from the [Releases](../../releases) page and **unzip** it into a folder you keep
   (the browser loads the extension from this folder, so don't delete it).
2. Open the extensions page of your browser:

   | Browser | Address |
   |---|---|
   | Chrome | `chrome://extensions` |
   | Brave | `brave://extensions` |
   | Edge | `edge://extensions` |
   | Opera / Vivaldi | `opera://extensions` / `vivaldi://extensions` |

3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped folder.
5. Open the [CS2 Workshop](https://steamcommunity.com/workshop/browse/?appid=730) – a shield bar appears at the bottom right.

Chrome may show a "Disable developer mode extensions" notice on startup; just dismiss it.

**Updating:** download the new release, replace the files in your folder, then click the reload icon on the extension card.

**Install from source:** `git clone` this repository and load the repository folder with *Load unpacked*.

## Usage

- The bar at the bottom right shows how many maps were hidden, dimmed and loaded from next pages. **Click it to switch the filter on/off.**
- Hover a map card: **⛔ Block author** (always filter this author) or, on dimmed maps, **✓ Allow author** (never filter this author).
- Settings: open the extension's **Details → Extension options**.

### How scoring works

| Signal | Points |
|---|---|
| Cyrillic characters in the description (default ≥ 8) | +70 |
| Spam phrase in the description (`Auto-connect`, `disable_workshop_command_filtering`, `connect IP`, `IP:port`, …) | +80 |
| Cyrillic characters in the title | +30 |
| Spam keyword in the title (`models`, `online`, `cheats`, `skins`, `random`, `bhop`, …) | +15 each, max +30 |
| Author on the blocklist | +100 |
| Very new Steam account | +10 |
| Author on the allow list | always 0 |

Maps with **≥ 30** points are dimmed, maps with **≥ 70** points are hidden. All values, keywords and phrases can be changed on the options page.
A legitimate map with a Russian-language description will be hidden by default – lower *Points for a Cyrillic description* or use **Allow author** if that bothers you.

## How it works

Steam's workshop pages are rendered by a React app with hashed CSS class names. The extension therefore does not depend on them:

1. The page embeds all map data (`title`, `short_description`, `creator`, …) as JSON (`valve-ssr-data`). The extension reads it from the current page, or fetches the same page from steamcommunity.com if it is not in the DOM.
2. Map cards are found through their `filedetails/?id=…` links.
3. Hidden maps are compensated by fetching up to 5 following result pages and appending clean cards to the current page.

Only `https://steamcommunity.com/workshop/browse/*` is accessed. Permissions: `storage` only.

## Development

```
├── manifest.json     Manifest V3
├── content.js        page logic: parsing, card detection, hiding, refilling
├── scoring.js        scoring rules and defaults (also used by the options page)
├── blocklist.js      generated starter blocklist
├── options.html/js   settings page
├── content.css
├── icons/
└── tools/
    ├── crawl.py      crawls workshop searches and regenerates the blocklist
    └── build.py      builds dist/workshop-spam-filter-<version>.zip
```

Load the repository folder as an unpacked extension and reload it after each change.

**Refresh the starter blocklist** (needs only Python 3, polite 1.5 s delay between requests):

```
python3 -I tools/crawl.py 5     # 5 pages per search term
```

Review the printed borderline authors and `spam_authors.json` before committing the new `blocklist.js`.

**Build a release zip:**

```
python3 tools/build.py          # -> dist/workshop-spam-filter-<version>.zip
```

### Releasing on GitHub

```
# bump "version" in manifest.json and add a CHANGELOG entry, then:
python3 tools/build.py
git tag v1.0.0 && git push --tags
gh release create v1.0.0 dist/workshop-spam-filter-1.0.0.zip --title "v1.0.0" --notes-file CHANGELOG.md
```

## Limitations

- If Steam changes the page's data format, the extension simply stops filtering; open an issue.
- Maps loaded to refill gaps are copies of the original cards; the description tooltip on hover is missing for them.
- Only the browse/search pages are filtered, not collections or detail pages.
