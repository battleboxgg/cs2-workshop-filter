# Changelog

## 1.0.0
- Scores every map in the CS2 Steam Workshop browse/search pages (Cyrillic description, auto-connect spam phrases, spam title keywords, blocked authors, brand-new accounts).
- Dims suspicious maps and hides clear spam; hidden maps are replaced by the next clean maps from the following pages.
- Hover buttons to block or allow an author; options page for thresholds, keywords, regex phrases and author lists.
- Bundled starter blocklist generated by `tools/crawl.py`.
